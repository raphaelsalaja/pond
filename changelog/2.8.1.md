## New

- On macOS, the Library window blurs your desktop behind the sidebar rail and toolbar.
- Appearance settings let you turn that blur off, pick the material, and set how much of your theme tints it.
- Group the Inbox by Type or Source as well as by Date, and fold each section.
- Fish chats group messages into bubbles, cite Saves, tags, and folders inline, and ask you to approve or deny each proposed change.
- Links to markdown and plain-text files, such as `llms.txt`, save as readable documents.
- Quick Preview has an Open Save button that opens the Save's details.
- The Save menu offers Add to Multiple Folders.
- Pond connects to OpenCode as an MCP server.

## Improved

- The Library panes sit in one rounded container, inset from the window edges.
- Switching libraries keeps Pond open instead of quitting and relaunching.
- The Library stays responsive while Saves are ingested, enriched, and synced.
- The Fish page fits on one column, and Routines show an empty state with New Routine.
- Pond waits out a site's rate limit instead of failing its Saves, and harvests at most two web Saves from one site at a time.
- GitHub repository cards keep retrying while GitHub generates the preview instead of falling back to a text cover.
- Downloads names the step a Save is actually waiting on.
- Long menus scroll instead of running past the window edge.

## Fixed

- The macOS app icon follows Dark, Clear, and Tinted appearance.
- X and Threads harvest again after changes to their web apps.
- YouTube Saves with SponsorBlock removal on keep their video.
- On-device captions and text recognition read a Save's original image instead of its avatar or thumbnail.
- Mark Processed, Snooze, and the Save menu work in the Inbox list and review deck.
- Closing a Save opened from the Inbox review keeps your place in the review.
- Groq models appear in the model list, and a new fish no longer joins a chat that is still running.
- The Consulted Saves strip under a fish reply scrolls with the mouse wheel, and the Save it opens takes the Details column.
- Library scan no longer hides a failed harvest when the Save still has its old files.
- Libraries on exFAT drives no longer report AppleDouble sidecars as damaged Saves, and backups of them succeed.
- The macOS menu bar icon shows how many downloads are in progress again.
- Hover previews on video cards start even after a drag or a card refresh.
- Videos no longer flash a platform cover before their first frame.
- Quick Preview shows one fullscreen button for videos, and its counter opens on the right image.
- Leaving a Canvas returns you to the folder you came from, not the Inbox.
- Range settings show three-digit values in full.
