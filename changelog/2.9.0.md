## New

- Group the Inbox by Type or Source as well as by Date, and fold each section.
- Open a Save's details from Quick Preview with the Open Save button.
- Markdown and plain-text links save as readable documents.
- Add to Multiple Folders is in the Save menu.
- Pond connects to OpenCode as an MCP server.

## Improved

- The Library stays responsive while Saves are ingested, enriched, and synced.
- Fish chats read like a conversation, with grouped messages, inline citations, and an Approve or Deny card for each proposal.
- The Fish page has a chat header and a simpler routines card.
- A bulk refresh sends each website at most two requests at a time, and waits when a site asks Pond to slow down.

## Fixed

- X Sync works again, and posts saved from X get their text, author, metrics, and media.
- Threads Saved and Liked Sync keep their first page.
- Groq models show in the fish profile and chat composer.
- A new fish opens a clean chat while another fish is replying.
- On-device image understanding reads a Save's original image instead of its avatar or thumbnail.
- Downloads explains why a Save is waiting.
- A failed refresh stays visible after a Library scan.
- GitHub preview cards retry instead of falling back to a text cover.
- Hover videos play after a drag or a missed hover.
- Quick Preview shows one fullscreen button and opens on the first item.
- A video no longer flashes an unrelated cover before its first frame.
- Escaping a Save opened from the Inbox returns you to the Save you were reviewing.
- Mark Processed, Snooze, and the Save menu work from the Inbox list, and a processed Save leaves the list.
- Long menus scroll instead of running off the window.
- Interface Zoom shows three-digit values.
- The rail's Library button returns to the Library instead of the Inbox.
- The menu bar icon shows the download count again.
- Libraries on exFAT drives ignore macOS sidecar files, so backups and Library Health work.
