## Important

- Linux downloads now name their architecture, like `Pond-2.7.0-x64.AppImage` and `Pond-2.7.0-arm64.deb`.

## New

- Pond runs on 64-bit ARM Linux, such as Asahi Linux, from its own AppImage and Debian package.
- Click Fetch All in the Sources toolbar to check every Source for new Saves.
- Turn on Fetch on Launch in Schedule settings to check your Sources each time Pond opens.
- Up and Down change a video's volume in 5% steps while Left and Right still seek.
- Click a playing video to pause it, and click again to resume.
- Set the carousel image you're viewing as the Save's thumbnail.
- Check for Updates checks right away and opens the update dialog while the download runs.

## Improved

- Folder sidebars with thousands of folders open in seconds and stay smooth while you scroll and sort.
- When Keep Running When Closed hides the Library for a minute, Pond releases its window and rebuilds it when you return.
- Idle queue workers, the search model, and hover video originals unload when you stop using them.
- Grid cards load a generated thumbnail instead of the full original.
- Selecting Saves, typing a search, and paging stay responsive in large Libraries.
- The animated fish slow down while your pointer rests, so they use less power.
- Hover previews wait until your pointer rests on a card before they load.
- Mute carries across every video preview and detached video window.
- The tag picker lists Create after the tags that already match.

## Fixed

- Card images that failed to load show the broken-image state instead of loading forever.
- Extension captures of images from other sites download again.
- YouTube downloads store one merged file.
- A Save's size updates after its video downloads.
- Rotating a tile a quarter turn swaps its width and height.
- Long parent names truncate on folder chips.
- The sidebar highlights only the page you're on.
- Collapsing a folder near the top of the sidebar eases into place instead of jumping.
- Show All opens the full Source collection instead of the previous folder.
- GitHub stars retry the generated repository preview when GitHub rate-limits it.
- Library shortcuts keep working while a toast is showing.
- Filtered Saves stay in place under an open tag picker.
- The extension shows its capture toast on the first save, and clamps long already-in-Pond descriptions.
- Large processing failures stay inside the status card.
- An unfinished hex color no longer paints the theme.
- Pressing an open popup's trigger holds it in place.
- MCP servers start without a Dock icon and quit when their host disconnects.
