## New

- Every sidebar panel header has a More actions button with that panel's actions, such as Library maintenance in Library, Retry Failed and Pause Queue in Downloads, and Check for Updates in Settings.
- Typing in ⌘K also finds actions inside submenus, such as Copy Pond Link under Copy Options.
- Right-clicking a Save on a Canvas offers Open Save, Open Original in Browser, Copy URL, and Copy Pond Link.
- Right-clicking a Notification in the Inbox offers Open, Mark Read or Unread, Snooze, Copy Message, and Delete.
- Right-clicking a Save referenced in a Fish chat opens the full Save menu.
- Tags add Copy Tag Name, folders add Copy Folder Link, and Smart Folders, Groups, and Saved Views add Copy Link.
- Downloads copies links for several rows at once, and finished downloads add Copy Pond Link.

## Improved

- Copy URL sits at the top level of the Save menu instead of under Copy Options.
- Inbox review cards size to the available space, so text-heavy Saves are readable while you triage.
- Drag-select scrolls faster at the window edge, and faster still the further past it you drag.
- Toolbar buttons line up with panel header actions, and Settings lists sit on a raised surface.

## Fixed

- Custom folder icons and colors stay visible while you rename a folder.
- Deleted or missing X posts show as not found in Downloads instead of timing out.
- Save Details and Inbox previews no longer show a YouTube cover as if it were the video's first frame.
- Hover previews start on video cards whose video loads under a pointer that is already resting on them.
