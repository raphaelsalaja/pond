## New

- Install Pond on Linux x64 as an AppImage or a deb package, with the browser extension, tray, and Launch at Login.
- Split a post with several images or videos into one save per slide with Split Into Saves, and each slide keeps the post's source, tags, notes, and folders.
- Turn on Split Into Saves for a source under Images > Carousels in Settings to split its new posts as they import.
- Split every multi-image save already in your library with Split Existing Saves.

## Improved

- Are.na Link blocks save as the web page they link to, with the page's cover image and an archive when automatic archiving is on.
- Convert Are.na Link saves from earlier versions into web pages with Convert Are.na Links in Storage settings.
- Delete After Import shows as a switch in a watched folder's details.
- The watched folder menu keeps Pause and Stop Watching together and moves Delete After Import to the end.
- Fish replies, imports, and storage stats no longer wait on unrelated work before they start.

## Fixed

- Restart installs a downloaded update instead of freezing Pond.
- The Instagram collections picker loads again, and an Instagram Account that files no collections asks you once to pick them.
- Changing which Instagram collections go into Folders syncs the Account when you leave its details.
- Saves whose files are gone from the library folder are marked failed instead of failing every enrichment pass.
- Unchecking Sensitive Content on a save stays unchecked after Pond analyzes the save again.
- The video seek bar responds to clicks and drags.
- Each Settings section opens scrolled to the top.
- The clear badge on filter chips is no longer clipped.
- Icons in the watched folder menu line up with their labels.
