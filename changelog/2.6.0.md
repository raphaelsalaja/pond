## Important

- When a source signs you out, Pond stops every queued request for it and asks you to sign in again, instead of retrying each Save.

## New

- Hover a status in Downloads to see why it's waiting, retrying, or failed, and when it resumes.
- Open a download's link in your browser from its context menu.
- Canvas boards have a minimap you can click or drag to move around, and hide from the zoom controls.
- Choose any Pond logo color as your Library logo, and turn on Match Library Logo to have the app icon follow it.
- Crop and zoom an image before it becomes your Library logo.
- Pick from 63 more folder icons.
- Threads Sources can import Saved Posts, Liked Posts, or both.
- Split a Save into separate Saves with the S key.
- Click a tag to open the Saves that use it.
- Drag smart folders to reorder them in the sidebar.
- Starred GitHub repositories use a custom preview when the repo sets one, and GitHub's generated card otherwise.
- On macOS, a Library shows in Finder as a Pond blue folder you can open.

## Improved

- Left and Right seek the video you're watching, and Shift with the arrow keys moves between Saves.
- Set how far the arrow keys skip in a video, from 5 to 30 seconds.
- Scrubbing a video timeline updates the preview in place instead of fading on every move.
- Folders nest only when you rest on the middle of a row, and a line shows exactly where a dropped folder lands.
- Drop a folder below the list to move it to the top level.
- The sidebar eases into place when a collapsed folder shortens it, instead of jumping.
- Smart folder rules show each folder's parent and each tag's group, so folders with the same name are easy to tell apart.
- YouTube Shorts use an upright thumbnail.
- Text covers render once when a Save and its library card both ask for one.
- If you move or rename your Library, Pond asks you to find it instead of opening an empty one.

## Fixed

- Add Tags and the A shortcut open the tag picker again.
- A source's Add to Folder rule applies to new Saves the moment they arrive.
- A new tag created inside a tag group stays in that group, and Uncategorized can always create tags.
- Large X imports no longer stall when replies wait for their parent post.
- X and Threads Saves from a batch import keep their own thumbnails.
- Image downloads no longer crash the download queue on Linux.
- Pages behind a login wall finish saving with their details instead of retrying.
- Pages with very large headers, like YouTube, save through the browser renderer.
- Reddit posts with a video on the parent, or an embedded YouTube, Vimeo, or TikTok link, save as video instead of a still.
- Unsaving a Reddit post no longer brings a deleted Save back into your library.
- Hover Preview plays and pauses a video without seeking as the pointer moves.
- Opening a Save from Recently Added keeps the preview open.
- Automatic fetch no longer re-imports Saves you've already deleted.
- Creating a subfolder on a collapsed sidebar folder shows the new row so you can name it.
- A Library that iCloud Drive synced as a package shows as a folder in Finder again.
