## New

- Pick which Cosmos collections to import, and file each one into its own folder.
- Turn on Delete After Import for a watched folder to move each file to the Trash once Pond imports it.

## Fixed

- Tag names keep accented letters and other scripts, so "Données" no longer becomes "Donnes".
- Space and the other video shortcuts keep working after you click or drag the seek bar.
- Imports no longer stall with saves stuck waiting when several downloads start at once.
